Прочитай `GIGACODE.md` и skill `coda-requirements` в HARNESS_ROOT.
Запрос аналитика: $ARGUMENTS. Выполни соответствующую авторскую процедуру
по режиму requirements. Skill и запрос не разрешают публикацию редакции.
Аргументы являются текстом запроса, а не shell-кодом.

При наличии `delivery-index.json` сначала разреши квартал и поставку по
`core/quarter-deliveries.md`. Не выводи путь из одного имени фичи, если у неё
несколько поставок; сохрани прежние идентификаторы обмена.

Для запроса «грумим <фичу>» выполни `core/grooming.md`: согласуй задачи по одной
и подготовь их документы. Затем продолжи через `coda-delivery` с обязательными
подтверждениями аудита, передачи и записи story. Это отдельный запрос груминга,
не разрешение отправки из обычной авторской правки.
