# Репозитории аналитической обвязки

Прочитай `GIGACODE.md`, раздел Repository exchange commands в `AGENTS.md`
и относящийся к запросу раздел `core/repository-exchange.md`.
Все пути разрешай от HARNESS_ROOT, установленного входной инструкцией.

Выбери только запрошенную операцию по этим договорам:

- «Синкани репы»: `python3 scripts/workspace.py bootstrap`, затем
  `python3 scripts/workspace.py sync` из HARNESS_ROOT.
- «Обнови код»: только `python3 scripts/workspace.py update-code`.
- «Сделай обратный дифф»: зарегистрированная операция reverse-diff по
  `core/repository-exchange.md`; не заменяй её ручным git diff.
- Обновление активной feature-ветки: `core/collaboration.md`, не полный sync.

При блокере следуй результату штатной программы; не обходи рабочую сессию,
непринятый импорт или человеческое слияние. Source — служебное bare-зеркало,
не рабочий каталог. Его заплата применяется на принимающей машине.
После sync начинай ответ точным report_message. Непустая обратная заплата
не означает совпадения репозиториев. Остальные проверки остаются в договорах;
этот skill не добавляет прав на операции с репозиториями.
