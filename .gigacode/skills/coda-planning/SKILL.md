# Планирование

**DOCS:** Прочитай `GIGACODE.md`, `modes/planning.md`, `core/entity-model.md`,
`core/run-loop.md` и `PROJECT_ROOT/planning/team.md`.

**RULE:** Режим `planning`; входы: intake, baseline, приоритеты, оценки,
состав команды, закрытые интервалы и риски. Пиши только артефакты режима.
На функциональность не больше одной истории для каждой роли AN/BE/FE/QA.
Используй единицы оценки из договора; не дели team-days на ресурсы повторно.
Расписание не превышает доступную ёмкость, зависимости и буфер учитываются.

**RULE:** Выполни `validate-workflow.py`, `validate-planning.py`, проверки
ссылок и соответствующую генерацию чернового плана по режиму.

**PROHIBITED:** Не переписывай утверждённые квартальные и командирские планы.
Утверждение принадлежит аналитику; фактические изменения ведутся отдельно.
