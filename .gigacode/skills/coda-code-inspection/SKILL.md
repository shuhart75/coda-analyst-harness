# Исследование кода

**DOCS:** Прочитай `GIGACODE.md` и `core/code-inspection.md`.

**RULE:** Начни с `workspace.py project-root`, затем `code-inspect.py route`
для полученного PROJECT_ROOT. Используй зарегистрированный абсолютный корень,
один контур и команды begin/locate/verify по договору. Входы: точный вопрос,
локальные инструкции контура, найденные модули и ближайшие тесты или контракты.

**RULE:** Зафиксируй ветку, коммит и состояние до чтения и проверь неизменность
после. Ответ по-русски содержит коммит и ссылки на файлы. Нулевой поиск
доказывает отсутствие совпадений только для запроса, контура и коммита.
Вопрос о коде сам по себе не начинает работу над функциональностью.

**PROHIBITED:** Не меняй code: никаких fetch/pull, переключений ветки, сборки,
форматирования, генерации, установки зависимостей, записей, коммитов или push.
При отсутствии роли code сообщи ограничение; не ищи другой клон по догадке.
