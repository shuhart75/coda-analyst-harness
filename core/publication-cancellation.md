# Отмена неподтверждённой передачи

Если отправленный кандидат устарел, не сливай его только ради разблокировки
нового комплекта. Удаление ветки само по себе не завершает передачу.
`deferred` относится к обработке результата разработчика и не отменяет публикацию.

После явного решения аналитика выполни:

```sh
python3 scripts/requirements-exchange.py cancel-publication PROJECT_ROOT FEATURE \
  --revision N --expected-commit FULL_SHA \
  --reason 'Причина отказа от кандидата' --analyst-confirmed
```

Команда проверяет точный коммит ветки и отсутствие редакции в целевой ветке,
сохраняет побайтовый снимок редакции в локальном служебном архиве
`cancelled-publications/` и добавляет отдельную запись `publication_cancellation`
в реестр. Исходная запись редакции, её digest, квитанции внутри снимка и прежний
манифест сохраняются. `publication_confirmed` остаётся `false`.
Аудит текущего входа команда не подтверждает и не сбрасывает.

Команда не удаляет ветку, не закрывает PR/MR и не меняет обычный клон code.
Человек закрывает старый PR/MR **без слияния**. Не создавай новый PR из этой ветки.
Повтор команды с тем же коммитом проверяет архив и возвращает `already-cancelled`.
Отсутствующая или изменившаяся ветка при первой отмене требует отдельного разбора.

Затем подготовь изменённый вход обычным `prepare`, соблюдая текущий main gate,
аудит и его подтверждение. Новая редакция получает следующий глобальный номер
и следующий номер этапа. В новой ветке проверки сохраняются точные файлы
отменённой редакции, а её запись манифеста имеет `state: cancelled`.
Активной становится новая редакция. Старый локальный манифест не переписывается.
После человеческого слияния новой ветки повтори `prepare`, затем штатный
`mark-published` для новой редакции. Отмена не является публикацией.

Изменение отменённой ветки, позднее слияние старого кандидата, повреждение архива
или смена места передачи блокируют продолжение. Недоступность code не разрешает
обойти отменённую историю публикацией в резервный каталог analytics.
Не переносить старое подтверждение аудита на изменённый комплект.

Архив отмены и прежний кэш манифеста нужны для следующей передачи: не удаляй их
при очистке workspace. При незавершённом `.pending` сначала проверь снимок;
команда не удаляет его автоматически. При переносе workspace сохраняй архивы и
реестр вместе; недоступный архив блокирует операцию. Старые версии обвязки,
не знающие `publication_cancellation`, не использовать для продолжения обмена.
