# Пакет разработки `<package-id>`, редакция `<revision>`

Это автономный неизменяемый вход для разработки в `<repository>/<contour>`.

## Порядок работы

1. Прочитать `manifest.json`, затем `request.md`.
2. Проверить контрольные суммы командой, указанной в пакете.
3. Зафиксировать исходную ревизию и состояние рабочего дерева.
4. Сверить каждый `REQ-*` и `SCN-*` с фактическим кодом и тестами.
5. Самостоятельно выбрать уместный технический подход и реализовать доступный объём.
6. Выполнить проверки и создать коммиты по правилам кодового репозитория.
7. Заполнить `receipt.json` по `receipt.template.json`.
8. Вернуть квитанцию по пути из корневого `handoff.json` общей папки передачи.

Входной пакет не меняется после отправки. Отклонения, невыполненная работа и дополнительная поставка отражаются в квитанции, а не исправляются во входных файлах задним числом.
