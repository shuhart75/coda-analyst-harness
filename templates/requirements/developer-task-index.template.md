## Назначение

Этот каталог содержит производные задачи разработки по функциональности `<feature-slug>`.

Корневой источник правил: `../requirements.md`.

Срезы в `../slices/` используются как аналитическая опора, если они помогают ограничить пользовательский сценарий, прототип или проверки. Задача разработки может ссылаться на один срез, несколько срезов или только на разделы корневых требований.

Индекс служит навигацией и не заменяет отдельные файлы задач. Каждый файл в этом каталоге должен быть самодостаточным рабочим пакетом: разработчик и языковая модель должны иметь возможность построить план реализации от файла задачи, не открывая корневые требования и срезы для поиска недостающих деталей.

## Синхронизация с требованиями

## Правила размера

- Целевой размер BE/FE/QA: 1-3 человеко-дня.
- Максимум для BE: 5 дней.
- Максимум для FE и QA: 10 дней.
- Для AN целевой и максимальный размер не задаётся.
- Одна задача содержит одну роль и один результат, который можно реализовать отдельным изменением.
