# Устаревший шаблон

Этот путь сохранён для совместимости старых сценариев развёртывания. Для новых и существенно перерабатываемых требований используй `feature-requirements.readable.template.md`.

Обвязка больше не создаёт требования в ISO-подобном формате и не формирует отдельные срезы или пакеты по контурам.
