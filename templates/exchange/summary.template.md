## Покрытие требований

Для каждого требования отдельно указываются полнота реализации (`full`, `partial`,
`none`, `unknown`), соответствие (`matches`, `differs`, `not-applicable`, `unknown`)
и проверка (`passed`, `failed`, `not-run`, `not-applicable`, `unknown`).
`not-applicable` для проверки допустимо только при подтверждённом отсутствии
реализации. При отсутствии доказательств проверки работающего поведения — `unknown`.

Для закрытия аналитик отдельно регистрирует текущий подробный `reviewed` итог
по каждому `REQ-*` и определяет судьбу всего остатка. `unknown` и `investigate`
блокируют закрытие. Нулевое выполнение допустимо в полном отчёте и может быть
закрыто только с явным решением по всему объёму. SDD сама этап не закрывает.
