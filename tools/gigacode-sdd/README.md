# Адаптер SDD Orchestrator

Исходники контроллера, аудиторов, веб-интерфейса и их тесты перенесены в
[shuhart75/sdd-orchestrator](https://github.com/shuhart75/sdd-orchestrator).
Здесь остаются только прежние точки входа. Изменения ядра следует вносить
в новый проект; закреплённая версия указана в `../sdd-adapter/runtime-lock.json`.

После первого обновления обвязки выполните установку в пользовательский каталог:

```sh
python3 tools/gigacode-sdd/install.py
```

Нужен доступ Git к приватному репозиторию. Допустима установка из уже полученной
копии: `python3 tools/gigacode-sdd/install.py --source /путь/sdd-orchestrator`.
Копия должна содержать закреплённый коммит. Сеть используется только при
явной установке. Повторный запуск установщика использует уже проверенную версию.
Python 3.10+ и Git достаточны, прав администратора и pnpm не требуется.

Прежние команды сохраняются, например:

```sh
python3 tools/gigacode-sdd/operator_web.py --config "/путь/запуска/config.json"
python3 tools/gigacode-sdd/bootstrap.py
python3 tools/gigacode-sdd/sdd-runner.py --help
```

Каталоги сохранённых запусков, конфигурация, рабочие копии, вопросы и ответы
не перемещаются. Остановите прежний контроллер через интерфейс, перезапустите
веб-сервер после обновления и продолжите сохранённую работу. Установка сама
ничего не запускает и не останавливает.

Альтернатива: работать непосредственно из нового проекта командой
`python3 sdd web`. Полное руководство и правила обновления находятся там.

Настройки адаптера: [../sdd-adapter/README.md](../sdd-adapter/README.md).
Прямой импорт внутренних Python-модулей из прежнего каталога больше не является
поддерживаемым интерфейсом; инструменты запуска используют закреплённое ядро.
